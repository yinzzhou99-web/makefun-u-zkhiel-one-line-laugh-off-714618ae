**One-Line Laugh-Off** — exactly one funny line, cold read, no setup, no explanation. An AI wrote the wedding vows, then paywalled the "I do".

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only, no network) writes the joke to `/output/entry.txt` and checks it against the gate (1–200 chars).
